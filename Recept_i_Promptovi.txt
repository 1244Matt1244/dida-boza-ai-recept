AI RECEPT: DIDA BOŽA - KORAK PO KORAK
Autor: Matej Martinović

============================================================
PREPORUČENI NAČIN: STREAMLIT APLIKACIJA
============================================================
Recept je moguće pokrenuti kroz interaktivnu web-aplikaciju
koja automatizira Fazu 4 (generiranje tekstova) i nudi
jednostavno sučelje za ponavljanje postupka.

Pokretanje:
  1. pip install -r requirements.txt
  2. streamlit run app.py
  3. Otvori http://localhost:8501 u browseru

U aplikaciji:
  - Odaberi proizvod, cilj i ton u bočnoj traci
  - Ostavi "Dry-run" uključen za demo bez API ključa
  - Klikni "Generiraj 3 objave"
  - Preuzmi rezultat kao .txt

Za stvarno generiranje potreban je OPENAI_API_KEY u .env datoteci.
Model: gpt-4o, temperatura 0.7.
Izlaz je identičan CLI verziji (vidi Faze 1-4 ispod).

============================================================
ALTERNATIVNI NAČIN: CLI SKRIPTA
============================================================
Ako želiš pokrenuti bez web-sučelja:
  python generate_content.py             (stvarno generiranje)
  python generate_content.py --dry-run   (demo bez API ključa)

Rezultat se sprema u output/generirani_sadrzaj.txt.
