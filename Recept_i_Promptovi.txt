AI RECEPT: DIDA BOŽA - KORAK PO KORAK
Autor: Matej Martinović

============================================================
PREPORUČENI NAČIN: STREAMLIT APLIKACIJA
============================================================
Recept je moguće pokrenuti kroz interaktivnu web-aplikaciju
koja automatizira Fazu 4 (generiranje tekstova) i nudi
jednostavno sučelje za ponavljanje postupka.

Pokretanje:
  1. pip install -r requirements.txt
  2. streamlit run app.py
  3. Otvori http://localhost:8501 u browseru

U aplikaciji:
  - Odaberi proizvod, cilj i ton u bočnoj traci
  - Ostavi "Dry-run" uključen za demo bez API ključa
  - Klikni "Generiraj 3 objave"
  - Preuzmi rezultat kao .txt

Za stvarno generiranje potreban je OPENAI_API_KEY u .env datoteci.
Model: gpt-4o, temperatura 0.7.
Izlaz je identičan CLI verziji (vidi Faze 1-4 ispod).

============================================================
ALTERNATIVNI NAČIN: CLI SKRIPTA
============================================================
Ako želiš pokrenuti bez web-sučelja:
  python generate_content.py             (stvarno generiranje)
  python generate_content.py --dry-run   (demo bez API ključa)

Rezultat se sprema u output/generirani_sadrzaj.txt.


============================================================
FAZA 1: GENERIRANJE POZADINE
============================================================
Alat: DALL-E 3 (putem ChatGPT-a)

ULAZ:
  - Prompt za DALL-E 3 (ispod)
  - Brend smjernice: topli, rustikalni, dalmatinski ugođaj, zlatni sat,
    prirodno svjetlo, bez ljudi, bez teksta
  - Format: 4:5 (1080×1350)

PROCES:
  DALL-E 3 generira 1–4 varijante scene prema promptu. Odabire se
  varijanta s najboljim svjetlom i kompozicijom (prostor za staklenku
  u prvom planu).

IZLAZ:
  1 odabrana slika pozadine (JPEG, 1080×1350), spremna za Fazu 2.

PROMPT:
"Golden-hour Mediterranean terrace scene features crusty sourdough topped with creamy cheese, glossy fig compote, and a thyme sprig on a handmade ceramic plate, surrounded by fresh figs, a jam-filled bowl, cheese and crackers, linen, and olive branches. Set against softly blurred stone villages, terracotta roofs, calm water, and distant hills, the rustic stone tabletop and warm natural light create an inviting, serene editorial food photograph with no people present."


============================================================
FAZA 2: LJUDSKA DORADA (INTEGRACIJA PROIZVODA)
============================================================
Alat: Canva (ili Photoshop)

ULAZ:
  - AI-generirana pozadina iz Faze 1
  - Stvarna fotografija staklenke Dida Boža (preuzeta s didaboza.hr)

PROCES:
  1. S web stranice (didaboza.hr) preuzeta je fotografija stvarne staklenke.
  2. U Canvi (ili Photoshopu) uklonjena je pozadina staklenke
     (Background Remover).
  3. Staklenka je pozicionirana u prvi plan generirane slike.
  4. Dodan je efekt meke sjene ispod staklenke kako bi se stopila s
     ambijentom i izvorom svjetla.

IZLAZ:
  Kompozitna slika: AI-generirani ambijent + stvarni proizvod brenda
  (JPEG, 1080×1350), spremna za Fazu 3.


============================================================
FAZA 3: OBLIKOVANJE (TIPOGRAFIJA)
============================================================
Alat: Canva

ULAZ:
  - Kompozitna slika iz Faze 2
  - Copy tekstovi (iz Faze 4 ili ručno napisani)
  - Brend banner "DIDA BOŽA • KREATIVNI KONCEPT"

PROCES:
  U Canvi su dodani tekstovi na slike:
  - Slika 1: "Slatko susreće slano / Jeste li probali smokvu uz sir?"
  - Slika 2: "Smokva. Kruh. Malo Mediterana. / Jednostavan zalogaj, veliki užitak."
  - Slika 3: "Mali ritual. Veliki užitak. / Pronađite svoj omiljeni način posluživanja smokve."
  Također, dodan je diskretni logo/banner "DIDA BOŽA • KREATIVNI KONCEPT"
  na dno svake slike.

IZLAZ:
  Tri finalne objave (JPEG, 1080×1350) spremne za objavu na Instagramu.


============================================================
FAZA 4: GENERIRANJE TEKSTOVA
============================================================
Alat: ChatGPT (ili Streamlit aplikacija / CLI skripta)

ULAZ:
  - Parametri: proizvod ("Ekološki džem od smokve 240 g"), cilj
    ("Interakcija, edukacija i emocionalna povezanost"), ton
    ("Topao i nostalgičan")
  - Brend smjernice: Dida Boža, Dalmacija, tradicija, prirodni sastojci
  - Publika: foodie scena, ljubitelji prirodnih proizvoda, Slow Living

PROCES:
  GPT-4o (temperatura 0.7) generira tri objave prema zadanom formatu:
  vizualni prompt, tekst objave i hashtagovi. Isti prompt koriste i
  Streamlit aplikacija (app.py) i CLI skripta (generate_content.py).

IZLAZ:
  Tri Instagram objave: vizualni prompt (za Fazu 1), uputa za ljudsku
  doradu (Faza 2), tekst objave i hashtagovi (5–8 po objavi).
  Rezultat se sprema u output/generirani_sadrzaj.txt.

PROMPT:
"Napiši tri kratka teksta za Instagram za brend Dida Boža. Prvi neka potiče interakciju o kombinaciji smokve i sira. Drugi neka potiče spremanje (saves) uz mediteranski ugođaj. Treći neka bude emotivan, o malim ritualima. Koristi topao ton i dodaj hashtagove."

NAPOMENA:
Streamlit aplikacija (app.py) i CLI skripta (generate_content.py) koriste
isti prompt za Fazu 4. Rezultat sadrži vizualne promptove za Fazu 1,
upute za Fazu 2 i 3, te tekstove i hashtagove za sve tri objave. Time se
cijeli postupak može ponoviti bez ručnog pisanja prompta.
