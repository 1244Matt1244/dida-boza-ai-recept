============================================================
PREPORUČENI NAČIN POKRETANJA: STREAMLIT APLIKACIJA
============================================================

Recept je moguće pokrenuti kroz interaktivnu web-aplikaciju
koja automatizira Fazu 5 (generiranje tekstova) i nudi
jednostavno sučelje za ponavljanje cijelog postupka.

Pokretanje:
  1. pip install -r requirements.txt
  2. streamlit run app.py
  3. Otvori http://localhost:8501 u browseru

U aplikaciji (bočna traka):
  - Proizvod, ciljna publika, cilj objava, ton komunikacije
  - Opcionalno: web stranica brenda i inspiracija / uzor
  - Dry-run način (bez API ključa) za demonstraciju
  - Generiranje vizuala putem DALL-E 3 (opcionalno, uz API ključ)
  - Format: statična slika ili karusel (4 slajda)

Za stvarno generiranje potreban je OPENAI_API_KEY u .env datoteci
ili u Streamlit Secrets. Model: gpt-4o, temperatura 0.7.
Izlaz je identičan CLI verziji (vidi Faze 1–7 ispod).

============================================================
ALTERNATIVNI NAČIN: CLI SKRIPTA
============================================================

Ako želiš pokrenuti bez web-sučelja:
  python generate_content.py             (stvarno generiranje)
  python generate_content.py --dry-run   (demo bez API ključa)

Rezultat se sprema u output/generirani_sadrzaj.txt.

- Cilj: Interakcija, edukacija i emocionalna povezanost

GLAVNI PROMPT:

"Napiši tri Instagram objave za hrvatski brend Dida Boža,
koji proizvodi ekološke džemove.

Proizvod u fokusu je ekološki džem od smokve.

Objava 1 treba potaknuti interakciju i komentare publike
kroz temu kombinacije smokve i sira.

Objava 2 treba predstaviti mediteranski način posluživanja
i potaknuti korisnike da spreme objavu.

Objava 3 treba stvoriti emocionalnu povezanost s publikom
kroz temu malih svakodnevnih rituala.

Koristi topao, prirodan i nostalgičan ton.
Tekstovi trebaju biti kratki, prirodni i prikladni za Instagram.
Dodaj relevantne hrvatske i engleske hashtagove.
Nemoj izmišljati informacije o proizvodu, certifikate ili cijene."

PROCES:

1. Unijeti parametre brenda, proizvoda, publike i cilja.
2. Generirati tri različita teksta.
3. Pregledati tekstove i ukloniti neprirodne formulacije.
4. Provjeriti usklađenost s vizualima.
5. Odabrati relevantne hashtagove.
6. Pohraniti konačne tekstove u Tekstovi_objava.txt.

IZLAZ:

i hashtagovima.

Napomena:
AI generirani sadržaj nije automatski konačni marketinški materijal.
Ljudska provjera i grafička dorada ostaju važan dio postupka.
